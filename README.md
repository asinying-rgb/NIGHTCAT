## ✨ 專案視覺與技術亮點

* **☀️ 傲嬌白晝防反光工程**：全網頁大標題、副標題全面升級「浮雕級全黑字體陰影（`text-shadow`）」，並在特定文字後方塞入極淡的微醺夜幕襯底，即使疊在明亮的咖啡廳照片上，依然字字鋒利。
* **🎛️ 高質感暗光控制面板**：控制台與音樂卡片採用不透明度高達 `0.92` 的深邃半透明黑玻璃面盤，完美襯托出純白文字與炫目霓虹按鈕。
* **🛡️ 雙語智慧防錯軌解耦**：改寫 JavaScript 底層比對邏輯，前端按鈕同步支援「精緻中文 ＋ 國際英文」混搭視覺，後端精準抽離文本比對，改認專屬代號標籤（Tag）與 `.includes()` 模糊捕捉，不論界面文字如何改動皆 100% 絕不搞亂。
* **✉️ Formspree 聯絡表單**：完整串接第三方後台表單收集系統，輸入框全面修正為深邃色調搭配純白訪客文字，兼顧安全與美觀。
